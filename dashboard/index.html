How the implied value is built

Every row is scored by the same function, impliedValue in lib/model.ts. No protocol name is ever special-cased.

implied = peer multiple × TVL × size factor × growth multiplier × maturity multiplier × breadth multiplier

  • Peer multiple — the median market-cap/TVL of live-token protocols in the same category, each peer winsorised to 0.005–3.0× so one outlier cannot set a category, then shrunk toward the global median when the category has few live peers.
  • Size factor — (TVL / $1B)−0.12, clamped to 0.60–1.40: bigger protocols earn a slightly lower multiple.
  • Growth — 1 + clamped 7-day TVL change (−40%…+80%) × 0.6.
  • Maturity — 0.70 + min(age, 4y) / 4y × 0.30; a protocol listed longer with no token counts for more. Unknown age counts as 365 days.
  • Breadth — +3% per extra chain, up to +15%.
